# Personal Reflection

While researching this topic, I was surprised by how divided the software engineering community is regarding AI. Some developers see AI as a revolutionary tool that increases productivity, while others are concerned about job security and declining software quality.

The most interesting discussion for me was about junior developers. I had not considered how AI might affect the traditional learning path for new programmers. If AI performs many beginner-level tasks, future developers may need to find new ways to gain practical experience.

I believe AI creates both opportunities and challenges. It can help developers work faster and automate repetitive tasks, but it can also encourage overdependence if used without understanding the generated code.

One concern I have is that developers may trust AI-generated code too much. If engineers stop analyzing and testing code themselves, software quality and security could suffer.

After completing this research, my opinion is that AI will not replace software engineers completely. Instead, engineers who understand both software development and AI tools will have an advantage.

To adapt in the future, I plan to continue strengthening my programming fundamentals, problem-solving abilities, communication skills, and software design knowledge while learning how to use AI tools effectively and responsibly.
